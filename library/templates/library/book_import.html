Automatyczne pobieranie okładek włączone

Każda zaimportowana pozycja zostanie automatycznie przeszukana w bazach: Open Library CDN, Open Library Search (Tytuł + Autor), Google Books Hi-Res oraz Wolne Lektury. Znalezione okładki zostaną pobrane i zapisane na stałe w bazie mediów.

Wymagany format pliku CSV

Plik CSV powinien używać przecinków jako separatorów oraz zawierać nagłówki kolumn w pierwszym wierszu (kodowanie UTF-8).

Rozpoznawane nagłówki:

Title Authors ISBN Publisher Published At Page Count Categories Language Description
